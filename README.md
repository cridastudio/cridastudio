# crida studio

Marketing, brand and technology studio in Caldes de Malavella (Girona, Spain). We work with companies, institutions and universities across Spain, and with biotech and bioprocess manufacturers across Europe.

[crida.studio](https://www.crida.studio/) · [Insights](https://www.crida.studio/en/insights/)

## Open data

We publish the data behind our studies under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), each set with a DOI on Harvard Dataverse. The same files are in [open-data](https://github.com/cridastudio/open-data) and on [Hugging Face](https://huggingface.co/cridastudio).
